description: Dump the current verified feature state for the pitch deck
---

Write `docs/pitch-state.md` containing:

1. Every feature that currently works, with the command or flow that demonstrates it.
2. Every feature that is partially working, and exactly what part is not.
3. Every number, claim, or metric shown anywhere in the UI, with its source.
   Mark each as ESTABLISHED or UNVERIFIED.
4. Known failure modes in the demo path.

This file feeds the pitch. Anything marked UNVERIFIED must not appear as a claim
in the deck. Do not pad the list with things that nearly work.
