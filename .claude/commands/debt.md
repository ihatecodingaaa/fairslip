description: Record a recurring defect class in docs/debt.md
---

Append a defect class to docs/debt.md: $ARGUMENTS

Format: `YYYY-MM-DD | class | where it appeared | structural prevention`

The "structural prevention" column must describe a change that makes the defect
impossible or automatically caught - not a reminder to be careful. If you cannot
name a structural prevention, write "none yet" rather than inventing one.
